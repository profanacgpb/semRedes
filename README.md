# Laboratórios de Redes de Computadores

Projeto didático sobre Internet das Coisas (IoT) e protocolos de comunicação. As páginas são estáticas e podem ser abertas diretamente no navegador.

## Conteúdos

- [Página inicial](./index.html): catálogo dos laboratórios.
- [IoT — fundamentos e protocolos](./IoT_Laboratorio_Interativo_2026_2.html): conceitos de IoT e animações de MQTT, CoAP e HTTP.
- [Simulador MQTT](./simulador_pacotes_mqtt.html): fluxo didático de pacotes MQTT sobre TCP/IP e níveis de QoS.
- [Simulador CoAP](./simulador_pacotes_coap.html): fluxo didático de pacotes CoAP sobre UDP/IPv4.
- [Animação de protocolos](./animacao_protocolos_mqtt_coap_http.html): comparação passo a passo de MQTT, CoAP e HTTP.

## Publicação

O GitHub Actions publica o conteúdo estático deste repositório no GitHub Pages a cada atualização da branch `main`.
